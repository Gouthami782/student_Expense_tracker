# Student Expense Tracker

A web application built to help students manage their daily expenses, monitor monthly spending, and stay within their budgets.

## Problem Statement

Students often struggle to track their personal expenses and identify where their money is being spent. This project helps students record expenses, analyze spending patterns, and manage their monthly budgets more effectively.

## Features

- **Add Expenses:** Record expenses with amount, category, description, and date.
- **View Expenses:** Display expenses in a table.
- **Edit and Delete:** Update or remove existing expense records.
- **Monthly Expense Summary:** Filter expenses by month and view monthly totals.
- **Monthly Budget:** Set and manage a monthly budget.
- **Budget Tracking:** View the amount spent and remaining budget.
- **Spending Alerts:** Receive alerts based on monthly spending.
- **Category-wise Spending:** Analyze expenses across different categories.
- **Browser Tab Icon:** Custom Student Expense Tracker favicon.

## How to Run the Project

### Prerequisites

- Java Development Kit (JDK)
- MySQL Server
- IntelliJ IDEA or another Java IDE

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/Gouthami782/student_Expense_tracker.git
   ```

2. Open the project in IntelliJ IDEA.

3. Configure your MySQL database and update your local database credentials.

4. Run the `StudentExpenseTrackerApplication.java` file.

5. Open your browser and visit:

   `http://localhost:8080`
